Dependencies:

	Python 3.8 or higher
	
	Packages (install with: pip install -r requirements.txt)
	----------------------------------------------------------------
	yfinance - Yahoo Finance data downloader
		Installation: pip install yfinance
		
	scikit-learn - Machine learning library
		Installation: pip install scikit-learn
		
	numpy - Numerical computing
		Installation: pip install numpy
		
	pandas - Data analysis and manipulation
		Installation: pip install pandas
		
	docopt - Command line argument parsing
		Installation: pip install docopt
	-------------------------------------------------------------------------

	Note: This project was migrated from Python 2.7 and yahoo_finance 
	to Python 3.x and yfinance due to deprecation of the old libraries.
